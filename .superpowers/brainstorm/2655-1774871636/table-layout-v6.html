計數器設計說明

  • 每位玩家的計數器包含三列：💰 金錢、📈 收入等級、⭐ VP
  • 每列都有 +1 / +5 / +10 和 -1 / -5 / -10 按鈕
  • 在 TTS 中會用 XML UI 的 Button 元件實現，點擊觸發 Lua callback 更新數值
  • 數值變化會同步到中央 GameState，確保存檔時一併保存
  • 計數器邊框顏色對應玩家色，方便識別
