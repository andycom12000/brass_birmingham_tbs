設計細節
  • 每位玩家區域放置 1 張幫助卡，共 4 張
  • 使用 TTS Custom Tile（2D 平面），鎖定位置
  • 內容摘要：
    • 6 種行動說明（Build / Network / Develop / Sell / Loan / Scout）
    • 建造需求與費用
    • 銷售流程
    • 計分規則
    • 回合結構
  • 支援中/英文切換 — 腳本控制翻面顯示不同語言版本（正面英文、背面中文，或透過按鈕切換貼圖）
  • 放置於玩家板旁邊，不干擾遊戲操作
多語言切換方式
  • 方案：正/背面雙語 — 翻面（Flip）即可切換語言
  • 正面 = 英文版、背面 = 繁體中文版
  • 簡單直覺，不需額外腳本
