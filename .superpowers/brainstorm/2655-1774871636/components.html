第二部分：元件系統設計（Components）

Brass: Birmingham 所有遊戲元件的 TTS 呈現方式

1. 主地圖板（Main Board）

呈現方式
  • 單一 Custom Tile（大型平面物件）
  • 正面貼圖：高解析度主地圖圖片（含城市、路線、市場、商人區、計分軌）
  • 固定於桌面中央，鎖定位置（Locked）
  • 使用 Snap Points 定義所有放置位置（城市建築格、連結路線、市場格）
Snap Points 配置
  • 城市建築格 — 每個城市的每個建築槽位一個 Snap Point，附帶 tag 標記城市名和產業類型
  • 連結路線 — 運河/鐵路路線放置點，tag 標記兩端城市
  • 煤炭/鐵礦市場格 — 價格軌道上的每個位置
  • 商人 Tile 格 — 商人區的放置位置

呈現方式
  • 每個 Tile 用 Custom Tile（2D 平面），正面為建築圖片，背面為未翻面狀態
  • 翻面（Flip）代表建築已售出/已消耗完資源
  • 每位玩家的建築 Tile 堆放在各自的玩家區域，依產業類型分疊
  • 腳本追蹤每個 Tile 的 等級（Level）、產業類型、擁有者、是否已翻面
  • Tile 上的資源方塊（煤炭/鐵礦/啤酒）用 3D 小物件放在 Tile 上方

3. 連結 Tiles（Canal / Rail）

🚢 運河 Canal
🚂 鐵路 Rail
  • 2D Custom Tile，橢圓或長條形，分運河（藍）和鐵路（灰）兩種
  • 放置於地圖上兩城市之間的連結 Snap Point
  • 每位玩家各有 14 個連結 Tile（對應玩家顏色）
  • 時代轉換時，腳本自動移除所有運河 Tile

  • 啤酒：金色 3D 小酒桶
  • 放在建築 Tile 上方代表該建築的產出
  • 從建築消耗時移至市場或移除
  • 公共資源區為溢出的備用池

7. 商人 Tiles（Merchant Tiles）

  • 2D Custom Tile，放置於主地圖商人區
  • 遊戲設置時依人數隨機抽取並放置
  • 顯示可接受的產業類型和啤酒需求

8. 玩家板（Player Board）

  • 每位玩家一塊 Custom Tile，上面印有各產業的建築槽位
  • 建築 Tile 從玩家板上取出放到地圖上（代表建造）
  • 使用 Snap Points 讓 Tile 整齊排列
  • 玩家板鎖定在各自角落位置
